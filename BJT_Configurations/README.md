# BJT Configurations (CE, CB, CC)

##  Objective

To simulate and analyze the three fundamental BJT configurations — Common Emitter (CE), Common Base (CB), and Common Collector (CC) — and compare their electrical characteristics, their input and output impedances - separate file is there for output impedance of the circuit

## ⚙️ Configurations Studied

###  Common Emitter (CE)

* High voltage gain
* Moderate input impedance
* Moderate output impedance
* Phase inversion between input and output

###  Common Base (CB)

* Low input impedance
* High output impedance
* No phase inversion
* Suitable for high-frequency applications

###  Common Collector (CC) (Emitter Follower)

* Voltage gain ≈ 1
* High input impedance
* Low output impedance
* Used for impedance matching



##  Results and Observations

* **CE configuration** showed significant voltage amplification with phase inversion
* **CB configuration** exhibited low input impedance and stable high-frequency response
* **CC configuration** acted as a buffer with near-unity gain and strong impedance matching characteristics


## 🧠 Key Learnings

* Each BJT configuration serves a different purpose in circuit design
* Trade-offs exist between gain and impedance
* CE is widely used for amplification, while CC is used for buffering
* Understanding these configurations is essential for analog circuit design



## 🚀 Conclusion

The simulations validate the theoretical behavior of BJT configurations and highlight their practical applications in amplification and signal conditioning.
